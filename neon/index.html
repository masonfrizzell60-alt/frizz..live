The format

Four games. One comment box. Zero downloads.

Everything runs in the browser and reads the live chat in real time, so a viewer on a cracked phone in a parking lot has exactly the same odds as anyone else.

The one that started it. Viewers type DROP to release a block, and the tower keeps every mistake. Chat has stacked it to 61 floors exactly once, on a Tuesday, at 2:14 AM, and nobody who was there has shut up about it since.
